# anti-slop-humanizer

The 29 AI-writing markers that the `dm-checker` agent (`.claude/agents/dm-checker.md`) scans every DM draft for live in [references/markers-29.md](references/markers-29.md). Any marker found fails the draft. The list detects only; nothing here rewrites text.
